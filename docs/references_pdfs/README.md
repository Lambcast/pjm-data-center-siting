# references_pdfs

Local PDF copies of journal articles, working papers, agency reports, and
industry whitepapers cited in `docs/references.bib`.

This directory is **gitignored** (see the project `.gitignore`). PDFs are
kept locally for personal reading and offline reference; they are not
redistributed through this public repository in order to respect publisher
and author copyrights.

File naming convention: match the BibTeX cite key, e.g.
`yu_2025_stochastic.pdf`, `shehabi_2024_lbnl.pdf`.
